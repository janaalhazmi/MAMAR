# MAMAR — UAT Testing Evidence

This directory contains screenshots collected during manual User Acceptance Testing (UAT) of the deployed MAMAR MVP.

## Purpose

- Provide visual evidence of executed test scenarios.
- Support the results documented in the QA Testing Report.
- Demonstrate successful end-to-end workflow validation.
- Maintain traceability between test scenarios, screenshots, and GitHub Issues.
